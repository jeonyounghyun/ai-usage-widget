AI 사용량 위젯 - 처음 읽어주세요
=================================

이 위젯은 Claude(claude.ai 채팅)와 GPT(Codex·ChatGPT Work)를 얼마나 썼는지
화면 한구석에 항상 보여줍니다. ChatGPT 일반 채팅 한도는 볼 수 없습니다.


■ 설치 (5분)

  1. 이 ZIP을 아무 폴더에나 풉니다. (다운로드 폴더여도 됩니다. 설치 중에 안전한 곳으로 옮겨 줍니다)
  2. 풀린 폴더에서  install.bat  을 더블클릭합니다.
     - 파란색 "Windows의 PC 보호" 창이 뜨면: 추가 정보 → 실행
     - "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면: 예
  3. 검은 창의 한글 안내를 따라갑니다. 직접 할 일은 세 가지뿐입니다.
     - Claude 로그인: 검은 화면에서 "Claude account with subscription" 선택 → 브라우저 로그인
       → 검은 화면에 ">" 입력창이 보이면 완료 → /exit 입력 후 Enter
     - "Codex나 ChatGPT Work를 쓰시나요?" → 쓰면 Y, 채팅만 쓰면 N
     - "Windows 켤 때 자동 실행?" → Y 또는 N
  4. 화면 왼쪽 위에 카드가 뜨면 끝입니다.


■ 평소 사용

  - 다시 보이기 / 켜기 : 바탕화면 "AI 사용량 위젯" 더블클릭 (이미 켜져 있으면 앞으로 나옵니다)
  - 끄기               : 위젯 우클릭 → 종료
  - 위치 이동          : 드래그
  - 작업표시줄에 붙이기: 더블클릭 (다시 더블클릭하면 카드로)
  - 설명 보기          : 숫자나 글자 위에 마우스를 올리면 뜻이 나옵니다
  - 설정               : 우클릭


■ 문제가 생기면 (위젯 우클릭 → "문제 해결")

  - 점검 실행      : 어디가 막혔는지와 해결 방법을 보여줍니다
  - 다시 로그인    : "재로그인 필요"가 뜰 때
  - GPT 연결하기   : 설치 때 N을 눌렀다가 나중에 GPT도 보고 싶을 때
  - 설치 폴더 열기 : 이 파일들이 있는 곳 (다운로드 폴더를 지웠어도 여기 있습니다)

  위젯이 아예 안 켜지면: 설치 폴더의  doctor.bat  더블클릭.
  설치 폴더는 보통  C:\Users\(내이름)\AppData\Local\Programs\ai-usage-widget  입니다.


■ 제거

  설치 폴더의  uninstall.bat  더블클릭.
  바로가기·자동 실행·위젯 폴더만 지우고, 함께 설치된 프로그램(Python, Win-CodexBar, Claude Code, Node.js)은
  다른 용도로도 쓰일 수 있어 남겨 둡니다. 지우고 싶으면 Windows 설정 → 앱에서 각각 제거하세요.
